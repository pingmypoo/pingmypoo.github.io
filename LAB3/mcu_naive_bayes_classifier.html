หลักการทางทฤษฎี: Gaussian Naive Bayes Classifier

สรุปสาระสำคัญสำหรับใช้ประกอบการทำรายงานส่งอาจารย์ในรายวิชา AI / Machine Learning

1. ทฤษฎีบทของเบย์ (Bayes' Theorem)

การจำแนกประเภทใช้หลักการหาความน่าจะเป็นภายหลัง (Posterior Probability) ของคลาส $C$ เมื่อทราบเวกเตอร์คุณลักษณะ $X = (x_1, x_2, ..., x_n)$:

P(C | X) = [ P(C) × P(X | C) ] / P(X)

โดยสมมติฐานหลักของ "Naive" คือ สมมติให้ทุก Feature เป็นอิสระต่อกัน (Conditional Independence) เมื่อทราบคลาส $C$

2. การแจกแจงแบบปกติ (Gaussian PDF)

เนื่องจาก Feature ของภาพยนตร์ (ทุนสร้าง, รายได้เปิดตัว, คะแนน, ความยาว) เป็นค่าตัวเลขต่อเนื่อง (Continuous Numeric) จึงคำนวณ Likelihood ด้วยฟังก์ชันความหนาแน่นความน่าจะเป็นแบบเกาส์เซียน:

P(x_i | C) = (1 / √(2πσ²)) × exp( - (x_i - μ)² / (2σ²) )

โดย μ คือค่าเฉลี่ย (Mean) และ σ² คือความแปรปรวน (Variance) ของฟีเจอร์นั้นในแต่ละกลุ่ม
